# Property Listing Marketplace

## Quick start

```bash
npm install
npm run dev
```

## Environment

Copy `.env.example` to `.env.local` and set your own values.

## Notes

- The app is scaffolded with stubbed authentication and AI services.
- Replace stubbed functions with real API integrations when your keys are ready.
- Daily cron report is generated by `scripts/daily-report.js` and writes to `daily-report.log`.
